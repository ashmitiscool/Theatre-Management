# Theatre Management

A school project for managing theatre operations, combining Python backend logic with HTML frontend interface.

## 📋 Description

This Theatre Management system provides functionality for organizing and managing various aspects of theatre operations. Built as an educational project, it demonstrates the integration of Python and HTML technologies to create a practical management solution.

## 🚀 Getting Started

### Prerequisites

- Python 3.x
- MySQL or compatible SQL database
- A web browser to access the HTML interface

### Installation

1. Clone the repository:
```bash
git clone https://github.com/ashmitiscool/Theatre-Management.git
cd Theatre-Management
```

2. **Database Setup:**
   - Create a new MySQL database named `cinemax`
   - Import the SQL tables from the `data` folder
   - Update the SQL connection password in all Python files to match your database credentials

3. Install any required Python dependencies (if applicable):
```bash
pip install -r requirements.txt
```

4. Run the application:
```bash
python app.py
```

### Database Configuration

⚠️ **Important:** Before running the application, you must:
1. Change the SQL connection password in all Python files to your database password
2. Import the pre-configured tables from the `data` folder into your `cinemax` database
3. Drop any existing tables to avoid conflicts
